## Summary

This release fixes a critical issue where iOS Safari would treat the application as a bookmark rather than a full Progressive Web App (PWA). The core issue was that the `manifest.json` and web app assets were being processed by the Next.js auth middleware, which could block iOS Safari's background manifest fetching.

## Changed / Fixed

- **iOS PWA Support**: 
  - Converted the dynamic `src/app/manifest.ts` to a static `public/manifest.json`.
  - Excluded `manifest.json` from the Next.js `middleware.ts` matcher so it can be fetched without authentication routing interference.
  - Ensured explicit Apple web app metadata (`apple-mobile-web-app-capable`) is defined in the root layout.
